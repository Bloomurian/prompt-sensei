# Stages and habits

Load this only when writing the "Habit to practice" line or answering a readiness request.

## Choosing the habit

Pick the single habit that helps most for this prompt, not mechanically the lowest-scoring one. Priority order:

1. **Safety first.** Secrets or private data outrank polish.
2. **Diagnosing:** evidence (expected vs actual, the exact error) outranks output format.
3. **Building:** a done-test and one boundary outrank formatting preferences.
4. **Verifying:** scope (which files, which version, against what) outranks response shape.
5. **Planning or writing:** audience, decision criteria and constraints outrank technical detail.
6. **Spend traps:** "start small" almost always comes first.

## Habit phrases

Use the phrase, or a close paraphrase that keeps the same idea.

| Habit | Say it like this |
|---|---|
| Name the outcome | Say the exact result you want before adding details. |
| Define done | End with how you will know it worked. |
| Show the evidence | Paste what you expected, what happened, and any exact error or message. |
| Point at the material | Name the file, page, track, tab or tool to use, and what to reuse. |
| Set one boundary | Add one limit: no new tools, minimal change, keep my naming rules. |
| Start small | Try 5 items or the first 10 minutes, then scale. |
| Ask for the shape | Say how you want the answer: a table, 3 options, a file, a checklist. |
| Add a check | Ask for a test, a sample, or an edge case that proves the result. |
| Protect private data | Swap secrets and private links for labeled placeholders. |
| Add a safety net | For anything hard to undo, ask for a dry run or a backup first. |
| Give the criteria | When comparing options, say what matters most. |

## Readiness by stage

| Stage | Judged on |
|---|---|
| Exploring | Clear question; safe |
| Diagnosing | Clear goal; evidence; safe |
| Building | Goal; context; what to use; boundary; output shape; done-test; safe |
| Verifying | Goal; context; scope; output shape; check; safe |
| Reusable | Goal; inputs; boundary; output shape; check; safe |
| Follow-up | Clear action; safe |

Labels: **Early** (normal for exploring), **Developing**, **Good**, **Ready**. Moving from Exploring to Building can lower the label simply because more is expected. That is not a step backward.
