# Changelog

## 1.1.0 (2026-11-09)

- **Stage-aware.** Classifies each prompt (Exploring, Diagnosing, Building, Verifying, Reusable, Follow-up) and judges it only against what that stage needs. Follow-ups and rough questions are never coached.
- **One habit to practice** on every rewrite, from a short habit list (`prompt-sensei/references/stages-and-habits.md`).
- **Readiness labels** (Early, Developing, Good, Ready) with `/prompt-sensei score`. A coaching signal, not a grade.
- **`/prompt-sensei watch`** for one-line tips on each reply, `stop` to silence, `help` for commands.
- **Safety pause** when a prompt contains secrets or private data.
- Prompt gallery (`examples/prompt-gallery.md`), eval checklist (`eval/`), philosophy doc.
- New banner and README.
